# DD-Resources (Dirty Dealing)

This repository serves as a **Static Asset Host** for *Dirty Dealing*. It is designed to provide on-demand access to game assets via remote URLs, ensuring modularity and reducing the initial build size.

## 📁 Repository Structure

- `/Cards/ChaosCards/`: Contains all the art assets for the Chaos Card System.

## 🚀 Asset Deployment Workflow

1. **Format**: Use optimized `.png` or `.jpg` files to ensure fast downloads and low memory usage in Unity.
2. **Naming**: Use `snake_case` and avoid spaces to prevent URL encoding issues.
   - *Good*: `cc_art_example.png`
   - *Bad*: `CC Art Example.png`
